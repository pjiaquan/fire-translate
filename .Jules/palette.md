## 2024-05-24 - Accessibility improvements for dynamically injected UI and Form Controls
**Learning:** Found that `<select>` elements without adjacent visible `<label>` tags need explicit `aria-label`s for screen reader support. Also, dynamically injected icon-only buttons (like `.history-delete-btn`) are completely opaque to screen readers without an `aria-label`. Buttons globally need `type="button"` to avoid unintended form submission behavior. Finally, explicit `:focus-visible` styling is crucial for interactive elements, as custom CSS often overrides native focus rings.
**Action:** When adding new interactive controls or creating dynamic HTML strings in JavaScript, always double-check for `type="button"`, appropriate `aria-label` (especially for icon-only components), and ensure `:focus-visible` remains visible across all themes and custom styles.
