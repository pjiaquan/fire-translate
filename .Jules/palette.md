## 2024-05-18 - Making Dynamically Injected UI Interactive Elements Accessible
**Learning:** When injecting custom interactive elements (like a `span` acting as a close button) dynamically into the DOM via `innerHTML`, we must proactively include ARIA roles (e.g., `role="button"`), `tabindex="0"` for keyboard focusability, and keyboard event handlers (`keydown` listening for 'Enter' and 'Space') to ensure full accessibility and discoverability, as native interactive elements (like `<button>`) do this automatically. Also, dynamically injected native `<button>` elements should be explicitly configured with `type="button"` and `aria-label` attributes to prevent accidental form submission and provide proper context to screen readers.
**Action:** Always verify that interactive elements, especially non-native ones (like styled spans) and native ones injected via JS, are fully equipped with proper accessibility attributes (`role`, `tabindex`, `aria-label`) and full keyboard event support (`keydown`) alongside `click` handlers. Ensure explicitly defining `type="button"` for injected buttons.
